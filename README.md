# GESTALTUNG Website

Static website for GESTALTUNG: an engineering studio, manufacturing platform, and lightweight product-commerce system.

## Local Preview

```powershell
python -m http.server 4173
```

Then open:

```txt
http://127.0.0.1:4173/
```

## GitHub Pages

This site is ready to be hosted from the repository root using GitHub Pages.

Recommended Pages source:

```txt
Branch: main
Folder: /root
```
